# Town artwork

The active town source art is retained here at full resolution. The built-in image generation tool created the artwork; prompt records accompany the sources.

- `rosie.png`, `millie.png`: brown long-haired dachshund walking sheets. `ImportTownSprites.py` packs them into map sprites.
- `pond-icon.png`: illustrated pond used by the minimap.
- `Playground.png`: tunnel, climbing dome, seahorse spring rider and picnic table.
- `Mailboxes.png`: six home-specific mailboxes.
- `PROPS.md`: playground and mailbox prompts. `ImportProps.py` crops and publishes those props.

Collectible spiders now use the sources in `../collections/`. Family bicycle sheets are in `../emerald/`. Superseded loose toys and draft spiders are not retained.
