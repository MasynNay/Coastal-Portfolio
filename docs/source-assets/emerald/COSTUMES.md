# Children’s costumes

Created with the built-in image-generation tool. Canonical transparent source sheets are `costume-ezra-spider.png` and `costume-fallyn-ladybug.png`. Runtime atlases live in `public/world/sprites/emerald/` and are packed with `scripts/PreparePeople.py`.

Prompt specification: preserve each character's recognizable brown hair, face and proportions from their existing family atlas. Draw a clean GBA-style 4-column, 8-row walking atlas, four alternating foot poses in each direction: south, southwest, west, northwest, north, northeast, east, southeast. Even spacing, consistent scale, transparent background, no text, scenery or detached effects. Ezra wears a black/red spider-hero costume with his long curly hair and uncovered face. Fallyn wears a red costume with black ladybug dots and a red eye mask, preserving her bangs and green eyes. The web effects are drawn separately by the game.

Fitzgerald’s blue-and-black costume is now shipped as `costume-fitzgerald-spider.png`, using his own atlas as the only reference. His existing face and hair are preserved, with a blue web emblem, black trousers and gloves, and blue boots. The full successful prompt and source/runtime paths are in `FITZGERALD.md`. Web effects are shared with Ezra’s game logic.
