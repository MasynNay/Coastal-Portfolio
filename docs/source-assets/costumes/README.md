# Family costume artwork

The active costume sheets use the original family faces and body proportions. The original archer, trainer, wizard and ocean-king sources remain in `../legacy/`; this folder supplies the airbender, adventurer and children’s outfits.

The built-in image-generation prompts and references are in `Prompts.json`. `PreparePeople.py` publishes canonical direction rows and shared world sizing. The rejected chibi redesign was removed.
