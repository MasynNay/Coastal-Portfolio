# Original character and animal artwork

Migrated before the old world project was removed. The original family sheets and four themed Masyn sheets now supply the detailed walking art directly; `PreparePeople.py` packs and normalizes them. `masyn-walk-home.png` supplies Masyn’s filled trousers and original features. The incomplete directional draft is kept only as an appearance reference.

The six animal originals prepare the duck, goose, axolotls and ambient fish via `PrepareLegacyAnimals.py`. Modern costume and action sources use these original identities and proportions, with their prompt records beside the new artwork.

`../DirectionRows.json` selects visually checked source views. The publisher constructs consistent opposite-facing rows, rather than trusting the source’s duplicated direction labels.
