# Character review

The selected full-body redraws are in `source-assets/people/`. All fourteen appearances now have sixteen walking and sixteen running poses for each of eight directions, with a separate idle cell. The artist references preserve the original outfits, recognizable hair/clothes and eye-color instructions. Family height differences remain in `Movement.js`; costume changes keep the same character ID and height.

The published artwork is reviewed in [walking directions](Characters-walk.png), [running directions](Characters-run.png) and the [animated family preview](CharacterPreview.gif). These use actual shipped PNGs, not the larger working sources.

The new drawings replace detached-limb movement. Walking has alternating contacts and arm swing; running uses its own bent-knee and elbow poses. The importer verifies complete source cells, preserves uniform action scale and reflects matching poses for opposite directions. Broad cloth, hair and accessories retain clear margins. Renderers use the same origin and selected appearance across the canvas and workshop.

All riding and fishing activities now use complete-body drawings in the selected costumes. The previously pending thirty-one activity atlases are replaced; no older component sources remain. Hyrulian Adventurer and the trainer use Masyn’s everyday drawings as the pose/identity reference, with costume-only edits across movement, rides, fishing and their Q actions. Ezra’s north-running correction retains his original walking/idle drawings and the shared family heights.

The fast leg playback came from advancing the animation clock at the running movement multiplier. `Gait.js` now keeps a shared stride phase while nominal running uses an 880-ms cycle (formerly about 583 ms in-world). Walking uses 1040 ms. Movement speeds remain 8.5/14 world units per second. Zero-time input redraws keep their stride rather than restarting it. There are still sixteen genuine authored movement poses per direction; no repeated frames or blended ghost limbs were added.

Both bike designs now keep their parked 1.3-unit size under all family members and costumes. Riders keep their normal body scale, sit at saddle height, and have room for complete wheels and feet. Nameplates clear the elevated rider's head. `RunningPreview.gif` shows actual run poses at the updated cadence, including the woodland archer.

The boat is the wakeboarding experience: an NPC drives while the player rides behind it. A cockpit mask keeps drivers' lower legs inside the hull. Skating uses a separate deck and body, with the deck flipping independently. Movement plus Q is exercised through actual keyboard event handlers. The styled return control is the single skateboard return button.

Freshwater and coastal/ocean catches have separate habitat pools, selected from the bobber's actual location before rarity is rolled. The guide labels those habitats. There are 500 bugs (100 of each group) and 250 aquatic creatures, with discovery history retained after release and unknown guide entries shown as locked silhouettes.

Automated checks inspect frame files, opposite directions, same-costume activity selection, input handling, ride routes, cache eviction, collection history and fishing habitats. Browser control was unavailable in this session; visual review uses actual exported frame sheets and automated renderer tests, not a claimed live-browser walkthrough.

`CostumePreview.gif` compares the revised Hyrulian Adventurer/trainer with everyday Masyn and shows Ezra’s corrected north run at the unchanged running cadence. Costume-only edits extend through all nine activity atlases and the ocarina/capture-ball actions. Pure north rows and the trainer’s north bicycle row received focused corrections before export.

The pier’s checkered START banner launches an automatic five-person axolotl race. Every racer uses their default costume and own colored mount. A shuffled finishing order controls the actual crossing times and winner announcement; menus pause the world clock. Finish, cancellation, travel and character selection restore the borrowed player appearance/position. The race camera frames all five ocean lanes without changing normal zoom preferences.

The latest Hyrulian Adventurer/trainer cycles are clothing edits of the approved wizard's actual poses. They retain one facing across every frame instead of mixing a turnaround into a stride. A 90-pixel whole-figure fit removes their old oversized appearance, while their shared world metric remains 96 pixels. The adventurer cap now covers the crown in every view and activity. `CostumeFrames.png` shows all south poses; `CostumePreview.gif` alternates walking/running toward the viewer and to the left. Re-exporting either fitted Q action is verified to produce identical PNGs.

Logical east is direction 2; atlas row 6 holds the east-facing image. The race now uses the movement direction helper rather than confusing those indices. Wider lanes contain the entire mounted sprite between floating ropes, each with a full starting gate. The winner portrait wears a crown. Boat/jet-ski minimap icons show the actual moored craft while clicks still navigate to reachable pier boarding points; their compact buttons remain separated on the smallest map.

Axolotl Drift uses three animated open-mouth eel heads, a matching body texture and the selected mounted family sprite. Space, Up, canvas taps and the Rise button share one input action. Physics/scoring, React controls and canvas artwork are separate modules. Game logic waits for required art, pauses with hidden tabs, saves a device-local best, and removes its animation loop/listeners on close. The foreground reuses the town's rippled sand tile, mirrored at its seams and scrolled by round distance; it stops when the run stops.

The adventurer PNGs have binary alpha, but smoothing their thin contours at game scale creates partially transparent edge pixels. `opaqueBody` in `Appearances.json` now opts the appearance into a nearest-sampled base plus smooth detail rendering. Both passes use the identical frame, coordinates and clipping. No new bitmap/cache is allocated, and explicitly faded effects retain their single-pass opacity. CSS sprite previews use the same two-layer treatment. The movement, activity and Q exporters preserve the setting across future artwork imports.

The latest Hyrulian style pass preserves the approved south/front drawings and repaints southwest, west, northwest and north in the same outlined, cel-shaded cartoon treatment. Each replacement source was checked for all 36 complete idle/walk/run poses before publishing; right-facing directions are still exact mirrors. The existing activity/ocarina sources were reviewed and retained. `HyrulianViews.png` compares idle, walking and running across all eight directions. `source-assets/people/StylePrompts.json` records the built-in imagegen prompts and saved source paths.

Mailbox artwork was intact; an inset doorway could sort its mailbox behind the building. The renderer now retains each real mailbox position while painting it in front of its own home. Per-image revisions refresh older browser caches. Two independent bike reservations and separated pond lanes allow both rentals to run at once; the extra End ride button was removed.
