# ASCII character references

The game-world figures are colored-text transformations of the references below.
The characters and reference artwork belong to their listed rights holders; they
are not original character designs by this portfolio. The display draws text
cells rather than embedding or hotlinking the original pictures.

`CharacterSources.json` records source checksums. `BuildAsciiArt.py` compiles the
verified local reference files into `CharacterFrames.json`. It preserves one
shared palette and one union crop throughout an animation to prevent color or
size changes between poses. The app makes no runtime calls to the source sites.
