# Source media

`images/` contains assets bundled by React: social icons, the CompTIA certificate, contact/hero backgrounds, the retained hero illustration and Vendetta's Pokémon video. Names describe the content instead of numbered drafts.

Project previews live in `public/images/projects/`, branding in `public/brand/`, and game artwork in `public/world/`. Their source/derivative relationship is documented under `docs/source-assets/`. The frozen original portfolio owns independent generated assets under `public/React-Portfolio/`; changing current source media must not change that demo.
