Photos currently uses the shared album configured in src/data/photos.js.
To use this local folder instead, set photoAlbum to null in that file.
Drop slideshow photos here (JPG, PNG, WebP, GIF or AVIF).
Restart the local preview after adding files, or run `node scripts/IndexPhotos.cjs` and reopen Photos.
Photos in this folder become public website assets when you eventually publish the site.
